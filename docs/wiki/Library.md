# Library 🎵

Everything you made or collected, kept with its tempo. Files are stored in `Music\AI Music Studio`. Three tabs:

## My tracks
Songs and loops from [[Create Music]] and files you added.

| Button / control | What it does |
|---|---|
| **▶** | Plays; the real waveform appears below. Click or drag in it to jump |
| **Search** | by name, tag or BPM: `124` finds 123–125 BPM, `120-130` a range; click a tag to show everything with it |
| **☆ Favourite** | marks the song |
| **Rename** (or double-click the name) | renames it |
| **Tags** | genre, mood or anything to search for (commas between tags) |
| **Add to project** | puts it into the [[Studio]], always on a **new audio track** (at bar 1, or at the playhead) |
| **Mastering** | opens the song in [[Mastering]] |
| **Export…** | saves a copy as WAV 16/24/32 bit, AIFF, FLAC or MP3 in a folder you choose |
| **Show file** / **Open folder** | opens Windows Explorer there |
| **Start on beat 1** / **Restore original** | cuts the lead-in of an older song so it starts on beat 1; the original is kept and can be restored |
| **Delete** | removes it from the library (**Delete file** also from the disk) |
| **Add files to the library…** | adds your own audio files |

## Stems
Stems saved from the [[Stem Splitter]], grouped by song: play, tags, **Add to project** (one new track per stem), **Export all…** (every stem as its own file).

## Samples
Your sample folders (nothing is copied, the files stay where they are).
- **Ableton Live found on this computer → Use this library**, or **Add folder…** for any folder; **✕** removes a folder from the list.
- Search by file and folder name, **▶** preview with waveform and seeking.
- Tempo is read from the name ("130 bpm"); **BPM?** measures it.
- **Studio: synced** puts the sample at the playhead on a new track and stretches it to the project tempo (pitch stays). **Studio: as is** puts it in unchanged. One-shots (under 1 second) are never stretched.
- **+ Library** copies it into *My tracks* (searchable, with tags, exportable).
