# Piano Roll ♪

Edit the notes of a MIDI clip. Open it with a double-click on a MIDI clip (or Shift+Tab / F12 in Ableton layout, Ctrl+E in Cubase layout). Double-click an empty MIDI track to make a clip first.

| Action | How |
|---|---|
| **Draw a note** | Draw tool: click (you hear it); drag the right edge for its length |
| **Move** | drag a note; arrow left/right one grid step, arrow up/down one semitone |
| **Select several** | **Select** tool and drag a frame around notes, Shift/Ctrl+click, or click into the piano roll and press **Ctrl+A** |
| **Delete** | Del, or the erase tool |
| **Quantize** | Ctrl+U: the selected notes (or all) to the grid; settings (Ctrl+Shift+U): strength, swing, note ends |
| **Hear a pitch** | click the keyboard on the left |
| **Grid** | from 1 bar to 1/64, triplets, free (Alt while dragging) |

Tools: Ableton **B** toggles draw mode; Cubase **1** select, **5** erase, **8** draw.

The built-in sound is a simple synthesizer; a master limiter keeps many notes at once from distorting. Notes can come from audio: **→ MIDI** in the [[Stem Splitter]].
